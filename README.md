# Rule-Based AI Chatbot

This project is a simple chatbot that responds to predefined user inputs using `if-else` logic.

## Features
- Handles greetings
- Handles common questions
- Exits cleanly on command
- Runs in a continuous loop

## Run the chatbot
```bash
python chatbot.py
```

## Example
```text
You: hello
Bot: Hello! How can I help you today?
You: how are you
Bot: I'm doing well, thank you! How about you?
You: exit
Bot: Goodbye! Have a nice day!
```
